Several Bracels

A demo for the roadmap: more than one Bracel on a page, sharing one spot finder. The meter times the script work of all the cats in each animation frame, so you can compare 1, 2, 3 and 5. Sound is off so the purrs don't pile up.

Page

How many

Changing the number reloads the page, so each count is measured from a clean start.

On: a cat isn't offered a spot another cat stands on (the bottom of the window is shared). Off: they may pile up.

Cost (last 2 s)

The guideline is under 1 ms of script per frame for Bracel (EXTENSION_GUIDELINES.md §5). Frames where every cat is still cost nothing and aren't counted.
